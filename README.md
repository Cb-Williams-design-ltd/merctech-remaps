# Merc Tech Re-Maps Demo
Static demo site ready for GitHub Pages.

## Publish
1. Create a new GitHub repository.
2. Upload `index.html`, `styles.css`, `script.js` and this README to the repository root.
3. Open repository Settings > Pages.
4. Under Build and deployment, select **Deploy from a branch**.
5. Choose `main` and `/ (root)`, then Save.

The enquiry form is intentionally demo-only and does not send customer data anywhere.
